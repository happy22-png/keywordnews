# keywordnews: Google News RSS 버전

키워드별 Google News RSS 결과를 서버에서 수집하고, 선택 기간을 다시 확인한 뒤 제목 유사도로 중복을 제거해 최신순으로 표시합니다. 뉴스 목록 수집에는 Gemini나 OpenAI API를 사용하지 않으므로 AI 토큰 소비가 없습니다.

## 동작 방식

- 키워드마다 `Google News RSS search`를 한 번 요청합니다.
- 최근 1일, 3일, 7일 또는 30일 범위 밖의 항목을 서버에서 다시 제외합니다.
- 제목의 공백·괄호·기호를 정규화하고 문자열 유사도를 비교해 중복 기사를 제거합니다.
- 제목에 포함된 숫자가 다르면 별개 기사로 유지합니다.
- 수집 및 중복 제거가 끝난 뒤 최신순으로 20건, 50건 또는 최대 100건을 표시합니다.
- 동일한 키워드·기간·표시 개수 결과는 브라우저에 30분간 저장합니다.
- 새로고침과 설정 저장은 RSS를 요청하지 않습니다. 사용자가 실행 버튼을 눌렀을 때만 요청합니다.
- 서로 다른 키워드 열 사이에서는 중복을 제거하지 않습니다. 같은 기사가 두 키워드에 모두 관련되면 양쪽에 표시될 수 있습니다.

Google News RSS가 반환하지 않은 기사는 가져올 수 없으므로 인터넷상의 모든 기사를 보장하지 않습니다. 한 피드가 제공하는 범위 안에서 기간에 해당하는 결과를 처리하며, 현재 화면의 최대 표시는 키워드당 100건입니다. RSS 주소는 공개 API 계약으로 명확하게 문서화된 인터페이스가 아니므로 Google의 변경에 영향을 받을 수 있습니다.

## 배포

이 폴더 전체를 저장소 루트에 반영한 뒤 Vercel에서 재배포합니다. `api/`, `lib/`, `index.html`, `style.css`, `package.json`, `build.cjs`, `vercel.json`이 모두 필요합니다.

이 버전의 뉴스 수집에는 환경변수가 필요하지 않습니다. 이전 버전에서 저장한 개인 API 키를 삭제할 수 있도록 설정 화면에 삭제 버튼을 유지했습니다. 그 버튼을 사용하려면 기존 `COOKIE_SECRET` 환경변수를 그대로 유지해야 기존 쿠키를 해독해 삭제할 수 있습니다. 기존 키를 이미 모두 삭제했거나 키 관리 기능을 사용하지 않는다면 `COOKIE_SECRET` 없이도 뉴스 수집 자체는 동작합니다.

## 검증

```sh
npm test
npm run build
```

외부 패키지 없이 Node.js 내장 기능만 사용합니다. 기간 필터, 최신순 정렬, 유사 제목 중복 제거, 숫자가 다른 제목 보존, 20건 제한, 키 없는 RSS 호출, 브라우저 캐시, 중복 클릭 방지를 테스트했습니다.
