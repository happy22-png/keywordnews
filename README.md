# keywordnews: Gemini + OpenAI 개인 키 버전

## 적용 상태

이 폴더는 Vercel에 배포할 수 있는 전체 프로젝트입니다. 기존 index.html만 교체하면 동작하지 않습니다. api/, lib/, style.css, package.json, build.cjs, vercel.json을 함께 반영해야 합니다. 현재 GitHub 연결에서 쓰기가 403으로 거부되어 원격 저장소 및 운영 사이트는 수정되지 않았습니다.

## 이용 방법

1. 배포한 HTTPS 사이트에서 설정을 엽니다.
2. Gemini와 OpenAI 키를 각각 입력하고 우선 제공자를 선택합니다. 하나만 등록해도 사용할 수 있습니다.
3. 저장 후 뉴스 브리핑 실행을 누릅니다. 저장 자체로 유료 뉴스 요청을 보내지 않습니다.
4. 우선 제공자가 HTTP 429를 반환하면 등록된 다른 제공자로 한 번 전환합니다. 401/403, 연결 오류, 잘못된 응답에는 전환하거나 자동 재시도하지 않습니다.
5. 두 제공자 모두 한도에 도달하면 중단합니다. 최소 60초 또는 제공자의 Retry-After에 따라 기다립니다. 대기 중인 제공자는 다음 키워드에서도 건너뜁니다.

키 입력란을 비우면 기존 키를 유지합니다. 개별 키 삭제 체크박스 또는 모든 키 삭제 버튼을 사용할 수 있습니다. 설정에서 키를 저장하는 것은 형식 확인과 보관이며, 실제 유효성은 첫 뉴스 요청에서 확인합니다.

## 키 보관 방식

- 키는 HTML, 소스 코드, localStorage에 저장되지 않습니다. 입력 직후에는 비밀번호 입력란 메모리에 존재하며 저장·취소 후 지웁니다.
- 서버가 AES-256-GCM으로 암호화하고, HttpOnly / Secure / SameSite=Strict / __Host- 쿠키로 7일간 보관합니다. 브라우저 JavaScript로 쿠키를 읽을 수 없습니다.
- 서버는 키 저장과 뉴스 조회 시 키를 처리하고 해당 제공자에 전송합니다. 서버 운영자를 신뢰해야 하는 구조입니다. 요청 본문, Cookie 및 Authorization 헤더를 로그에 기록하지 마세요.
- 사용자 계정 구분이 아니라 **브라우저 프로필 구분**입니다. 서로 다른 사람이라도 같은 브라우저 프로필을 쓰면 키를 공유합니다. 공용 기기에서는 사용 후 삭제하세요.
- 쿠키를 삭제하거나 만료되면 키를 다시 입력해야 합니다. 서버 암호화 비밀값을 바꾸면 기존 쿠키는 모두 무효화됩니다.
- 중앙 키 데이터베이스는 없습니다. 삭제는 현재 브라우저의 쿠키를 지우는 동작이며, 이미 복사된 쿠키까지 개별적으로 취소하는 서버 세션 기능은 없습니다. 유출 시 제공자에서 API 키를 폐기하세요.
- 이전 버전의 briefing_api_key 평문 저장값은 새 화면이 열릴 때 삭제합니다. 기존 키를 자동 전송하지 않으므로 다시 입력해야 합니다.
- 외부 Tailwind 실행 스크립트를 로컬 스타일시트로 대체했습니다.

## Vercel 배포

1. 이 폴더의 내용을 happy22-png/keywordnews 저장소 루트에 반영합니다. .env.example은 예시일 뿐이며 실제 비밀값을 저장소에 올리지 마세요.
2. Vercel 프로젝트 환경변수에 COOKIE_SECRET을 설정합니다. 아래 명령으로 생성한 32바이트 base64 값을 사용합니다. 이 값은 API 키가 아니라 쿠키 암호화용 서버 비밀값입니다. 채팅이나 소스 코드에 붙여 넣지 마세요.

   ```sh
   node -e "console.log(require('crypto').randomBytes(32).toString('base64'))"
   ```

3. Framework Preset은 Other, 프로젝트 루트는 이 파일들이 있는 폴더로 둡니다. vercel.json에 빌드 명령과 public 출력 폴더가 설정되어 있습니다. Node.js 22를 사용합니다.
4. 다시 배포하고 HTTPS 주소로 접속합니다. HTML 파일을 직접 여는 file:// 방식은 쿠키 API를 사용할 수 없습니다.
5. 선택 환경변수: OPENAI_MODEL(기본 gpt-4.1-mini), GEMINI_MODEL(기본 gemini-3-flash-preview), APP_ORIGIN(예: https://keywordnews.vercel.app). APP_ORIGIN을 설정하면 정확히 그 주소에서만 변경·조회 요청을 허용합니다. 미설정 시 현재 요청의 HTTPS 호스트를 사용하여 Vercel 미리보기 주소도 지원합니다.

각 이용자의 제공자 계정에 비용이 청구됩니다. 서비스 운영자 API 키를 공용 기본값으로 사용하지 않습니다. 모델 접근 권한과 잔액은 이용자마다 다를 수 있습니다.

## 사용량 최적화

- 같은 키워드·기간의 뉴스는 브라우저에서 30분간 재사용하고 최근 50개 조합까지만 저장합니다.
- 페이지 진입·설정 저장은 뉴스 모델을 호출하지 않습니다. 키 등록 여부를 읽는 자체 서버 요청만 발생합니다.
- 키워드당 최대 기사 4개, 짧은 한 문장 요약, 출력 토큰 상한을 사용합니다.
- 조회 중 버튼을 잠그고, 오류 시 추가 새 요청을 중단합니다.
- 기사 옆에 응답 제공자와 전환 여부, 클릭 가능한 검색 근거를 표시합니다. 제공자가 반환한 검색 근거 URL에 연결되지 않는 기사는 제외합니다. 이는 날짜와 모든 보도 내용의 진실성 검증을 보장하지 않습니다.
- 표시되는 토큰은 제공자가 보고한 값만 합산합니다. 검색 도구 요금, 실패 응답의 미보고 사용량은 포함하지 않습니다.
- 캐시와 실행 잠금은 현재 브라우저/화면 기준입니다. 여러 탭·기기·동시에 진행 중인 요청 전체에 대한 비용 상한이나 분산 잠금은 제공하지 않습니다. 쿠키에 담긴 대기 상태는 동시 응답 간 덮어쓰기가 가능합니다. 대규모 운영에는 공유 저장소 기반의 요청 제한이 필요합니다.

## 검증

```sh
npm test
npm run build
```

외부 패키지 설치 없이 Node.js 내장 기능으로 실행됩니다. 암호화·변조·만료·삭제, 사용자 분리, 출처 검사, 양방향 429 전환, 일반 인증 오류 시 미전환, 재시도 중단, 캐시, 중복 클릭, 키 입력 제거 등을 모의 응답으로 확인했습니다. 브라우저에서 설정 화면도 확인했습니다. 실제 유료 API 호출 및 Vercel 배포 테스트는 아직 수행하지 않았습니다.
